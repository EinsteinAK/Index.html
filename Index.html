7 core types
int
Whole numbers, arbitrary precision. Perfect for counting & indexing.
# integer
x = 42
y = -1_000_000
print(x + 8) # 50
float
Floating-point numbers. For precise decimal & scientific values.
# floating point
pi = 3.14159
avogadro = 6.022e23
print(pi * 2) # 6.28318
str
Immutable sequence of Unicode characters. Text data & formatting.
# string
name = "Python"
emoji = "🐍 glass"
print(name[0]) # 'P'
bool
Truth values: True or False. Backbone of logic & conditionals.
# boolean
is_ready = True
has_glass = False
print(is_ready and not has_glass) # True
list
Ordered, mutable sequence. Can hold mixed data types.
# list
langs = ["Python", "JS", "Rust"]
langs.append("Go")
print(langs[0]) # Python
tuple
Immutable ordered sequence. Ideal for fixed collections.
# tuple
point = (4.5, -2.1)
rgb = (255, 128, 0)
print(point[0]) # 4.5
dict
Key-value mapping. Hash table, mutable, fast lookups.
# dictionary
user = {"name": "Ada", "age": 36}
user["lang"] = "Python"
print(user["name"]) # Ada
